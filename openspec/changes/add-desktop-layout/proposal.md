# Proposal

## Why

在電腦的寬螢幕上，App 仍是手機寬度的一欄，記帳時輸入表單和明細上下堆疊，新增一筆後要往下捲才看得到；上方頁籤也佔掉一列空間。我想在電腦上改成「左邊輸入、右邊明細」，打完一筆馬上在右邊看到，並把頁面切換收進 ☰ 選單。

## What Changes

- **電腦版（寬度 ≥ 900px）**：
  - 上方頁籤改為標題列左側的 ☰ 選單按鈕，按下後選單從左側滑出，列出「記帳／日曆／比較」，選擇後自動收回
  - 標題列顯示目前所在頁面名稱（例：記帳本・日曆）
  - 記帳頁分成左右兩欄：左欄為月份選擇＋本月統計＋新增表單，右欄為明細
  - 新增成功後，新的那一筆立即出現在右欄明細，並短暫醒目標示
  - 右欄明細固定在畫面上，筆數多時在欄內捲動
- **手機版（寬度 < 900px）**：維持目前的上方頁籤與單欄排列
- 日曆、比較頁在電腦上維持單欄，置中顯示

### Non-goals（本次不做）

- 選單內的「管理」功能（分類管理、資料匯出等）
- 選單展開子項目
- 日曆、比較頁的多欄版面
- 記住選單或版面的偏好設定

## Capabilities

### New Capabilities
- `ledger-page`: 記帳頁的版面：電腦版左右兩欄（輸入／明細）、手機版單欄，以及新增後在明細中醒目標示新紀錄

### Modified Capabilities
- `app-navigation`: 「頁籤」需求改為只適用手機寬度；新增電腦版 ☰ 選單需求

## Impact

- 新增前端程式：☰ 選單元件
- 修改前端：`App.jsx`（版面結構、選單、新紀錄標示）、`TransactionList.jsx`（醒目標示）、`App.css`（電腦版版面與選單樣式）
- 後端、資料庫、API 不變；不新增相依套件
