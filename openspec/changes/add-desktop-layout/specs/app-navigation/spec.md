# Spec Delta

## MODIFIED Requirements

### Requirement: 頁籤
螢幕寬度小於 900px 時，前端 SHALL 在頁面上方提供「記帳」「日曆」「比較」三個頁籤，依此順序排列，打開 App 時預設停在「記帳」。一次只顯示一個頁籤的內容。寬度 900px 以上時不顯示頁籤，改用「電腦版選單」。

#### Scenario: 頁籤順序與預設頁
- **WHEN** 使用者在手機寬度打開 App
- **THEN** 頁籤依序為「記帳」「日曆」「比較」，且停在「記帳」

#### Scenario: 切換頁籤
- **WHEN** 使用者點選「日曆」
- **THEN** 畫面只顯示日曆頁的內容，「日曆」頁籤呈現選取狀態

#### Scenario: 電腦寬度不顯示頁籤
- **WHEN** 使用者在寬度 1280px 的螢幕打開 App
- **THEN** 頁面上方沒有頁籤，標題列左側有 ☰ 按鈕

## ADDED Requirements

### Requirement: 電腦版選單
螢幕寬度 900px 以上時，前端 SHALL 在標題列左側顯示 ☰ 按鈕。按下後選單從左側滑出，依序列出「記帳」「日曆」「比較」並標示目前所在頁面，其餘畫面以半透明遮罩覆蓋。選擇項目、按 ✕、點遮罩或按 Esc 時選單 MUST 收回。標題列 MUST 顯示目前頁面名稱。打開 App 時預設停在「記帳」。

#### Scenario: 打開選單
- **WHEN** 使用者在電腦寬度按 ☰
- **THEN** 選單從左側滑出，列出「記帳」「日曆」「比較」，目前頁面為選取狀態

#### Scenario: 選擇頁面後自動收回
- **WHEN** 選單打開時使用者點選「比較」
- **THEN** 選單收回，畫面顯示比較頁，標題列顯示「記帳本・比較」

#### Scenario: 不選擇直接關閉
- **WHEN** 選單打開時使用者按 ✕、點遮罩或按 Esc
- **THEN** 選單收回，頁面維持不變

#### Scenario: 預設頁
- **WHEN** 使用者在電腦寬度打開 App
- **THEN** 顯示記帳頁，選單為收起狀態，標題列顯示「記帳本・記帳」
